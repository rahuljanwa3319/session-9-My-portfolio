## 📖 About

**My Portfolio** is a personal portfolio website developed as part of **Session 9** of my web development learning journey.

The website provides an overview of my profile, technical skills, projects, education and interests while demonstrating my understanding of modern frontend development.

The project also includes interactive features such as **Dark/Light Mode** and an **interactive quiz**.

---

## ✨ Features

### 👤 Personal Profile
A dedicated section introducing myself, my background and my career interests.

### 🛠️ Technical Skills
Displays the programming languages, technologies and tools that I am currently learning and working with.

### 💻 Projects
A collection of projects that demonstrate my practical programming and web development skills.

### 🌗 Dark & Light Mode
A theme-switching feature that allows users to switch between:

- ☀️ Light Mode
- 🌙 Dark Mode

The theme can be changed using the toggle button.

### 📝 Interactive Quiz

The portfolio includes a simple interactive quiz.

**Quiz details:**

- 5 Questions
- 1 Mark per Question
- Submit Button
- Automatic Score Calculation
- Final Score Display

### 📱 Responsive Design
The website is designed to work across different screen sizes including:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📟 Tablet

## 📝 Quiz System

The quiz is implemented using JavaScript.

### Quiz Flow

```text
Start Quiz
    ↓
Answer 5 Questions
    ↓
Click Submit
    ↓
JavaScript Checks Answers
    ↓
Calculate Score
    ↓
Display Final Marks
```

Example:

```text
Question 1 → 1 Mark
Question 2 → 1 Mark
Question 3 → 1 Mark
Question 4 → 1 Mark
Question 5 → 1 Mark

Total → 5 Marks
```

## 🚀 Getting Started

### 1. Clone the repository


### 2. Open the project

```bash
cd session-9-My-portfolio
```

### 3. Run the website

Open:

```text

```

in your browser.
